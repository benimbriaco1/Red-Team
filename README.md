# Red-Team

🔴 This repository contains my Red Team Tool for CSEC 473. It is a PHP script, and the corresponding Ansible playbooks which are used to deploy this script to both Windows and Linux hosts. 

🔴 The Ansible sets up IIS and Apache on Windows and Linux systems respectively, and the PHP creates a web shell which can be used for remote command injection. 

🔴 The desired outcome is a web server running on every single host that can be accessed via browser and subsequently used to remotely send commands
